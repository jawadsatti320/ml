# 🤖 Machine Learning Projects — YOLOv8 & ML Notebooks

A collection of practical machine learning projects including **real-time vehicle tracking with YOLOv8** and various ML experiments in Jupyter notebooks.

---

## 📂 Projects Inside

| Project | Description |
|---------|-------------|
| `Track-and-count-vehicles-with-yolov8` | Real-time vehicle detection, tracking & counting using YOLOv8 |
| `notebooks/` | ML experiments — classification, regression, and data analysis |

---

## 🚗 Highlight: Vehicle Tracking with YOLOv8

A computer vision pipeline that detects and counts vehicles in real-time from video streams using **YOLOv8** (state-of-the-art object detection model).

```
Video Input (camera / file)
        ↓
  YOLOv8 Detection
  (bounding boxes per frame)
        ↓
  Object Tracking
  (unique ID per vehicle)
        ↓
  Vehicle Count Output
  (cars, trucks, bikes)
```

**Real-world use cases:**
- Traffic monitoring systems
- Smart city infrastructure
- Parking lot management
- Highway toll automation

---

## 🚀 Key Concepts Covered

- YOLOv8 model loading and inference
- Real-time object detection on video frames
- Object tracking (assigning persistent IDs)
- Counting logic with crossing-line detection
- OpenCV for video processing

## 🛠️ Tech Stack

| Tool | Purpose |
|------|---------|
| Python | Core language |
| YOLOv8 (Ultralytics) | Object detection model |
| OpenCV | Video capture & frame processing |
| NumPy | Numerical operations |
| Jupyter Notebook | ML experiments |

## ⚙️ Setup

```bash
git clone https://github.com/jawadsatti320/ml.git
cd ml
pip install ultralytics opencv-python numpy jupyter
```

**Run vehicle tracker:**
```bash
python Track-and-count-vehicles-with-yolov8
```

**Run ML notebooks:**
```bash
jupyter notebook
# Open any notebook from the notebooks/ folder
```

## 📊 ML Notebooks

The `notebooks/` folder contains experiments covering:
- Supervised learning (classification & regression)
- Feature engineering and selection
- Model evaluation metrics
- Data visualization and EDA
